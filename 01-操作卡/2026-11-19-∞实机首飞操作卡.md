## 七、飞行中看什么（一条时间轴）

| 时刻 | 预期日志 | 这时的动作 |
|---|---|---|
| T+0 | 起飞，`now(...) to (0,0,0.80,0)` 刷屏 | 手放遥控器上，别动 |
| T+8 s | `Hovering at (...)` 约 1 秒 | 无 |
| T+9 s | `入轨：s0=2.03 m，目标 1.0 圈 = 2.74 m` | 开始画 ∞ |
| T+9~23 s | 每 0.5 s 一行 `s=0.30/2.74 m  e=0.02 m  v=0.21 m/s ...` | **盯飞机的形状，不盯屏幕** |
| T+23 s | `∞ 轨迹完成：实际弧长 2.73 m，闭合误差 0.0x m，用时 xx s` | 看它开始回原点 |
| T+25 s | `已回到原点，径向偏差 0.0x m` | 无 |
| T+26 s | `Precision landing complete.` | **立刻准备 disarm** |

**首飞预期**：`k_gate 0.30` → 速度约 0.21 m/s → 单圈 13–15 s，全程约 25 s。

### 三条"这是正常的"

1. `k_gate 0.30` 飞得很慢，**就是要慢**；
2. 日志里 `到达目标点，巡航点任务完成` 在回原点时会刷屏（`mission_pos_cruise` 的老毛病）——无害；
3. `Precision landing complete` ≠ 已上锁，**必须手动 disarm**。

## 十、异常处置

| 现象 | 原因 | 动作 |
|---|---|---|
| 飞机画 ∞ 时明显跑偏/打摆 | 定位漂 / 参数偏 | **拨 SwD 接管**，稳住后落地 |
| 日志 `!! 横向偏差超限 ... 已转悬停` | 程序主动冻结悬停 | **别慌**，程序没死；先看屏幕，接管或等 3 秒再决定 |
| 一直 `Waiting for OFFBOARD mode` | 没拨 SwD / 档位映射不对 | 拨杆；确认 SwD 是 OFFBOARD 档 |
| pane 1 报 device / 时间同步错误 | 硬件链路 | **别输 1**，找现场负责人 |
| 飞到一半撞到边界/物体风险 | — | 第一动作：接管 |
| SSH 断了 | 网络 | 飞机继续按 setpoint 飞完并降落，**飞手接管优先** |
| 落点不在原点 | 收尾判据 | 看 `已回到原点` 那行的偏差，> 0.1 m 记下来 |

**接管本身不扣分**（任务书原话），但要在记录里写清完成情况与异常原因。

## 十四、飞完清理（防止别的组直接拿去飞）

**为什么必须清**：整套算法的源码就在 `template.h` 末尾追加的 388 行里。
只删 `figure8.cpp` 不够——别人一句 `grep traj_send template.h` 就能拿走。

**先确认数据已回传**（第十一节），再清。三步：

### ① 把清理脚本挪出家目录（脚本会删 `~/fig8`）

```bash
cp ~/fig8/fig8-clean.sh ~/fig8-clean.sh && chmod +x ~/fig8-clean.sh
```

### ② 先预览（这一步不删任何东西）

```bash
bash ~/fig8-clean.sh
```

会列出五类：figure8 四件套 + 二进制、`~/fig8` 目录与所有 tgz、CSV 数据、
`template.h` 里的追加段、`CMakeLists.txt` 里的 figure8 目标。

### ③ 确认后真删

```bash
bash ~/fig8-clean.sh --go
```

它会：删文件 → 还原 `template.h` 与 `CMakeLists.txt`（取最早的备份＝追加之前的原件）→ 重新编译 → 打四行验收。

**四行都要对**：

```
1) template.h 里 traj_send 次数（应为 0）: 0
2) CMakeLists 里 figure8 次数（应为 0）: 0
3) devel/lib/mission 下应只剩官方三个： hover square avoidance
4) 残留 tgz 数量: 0
```

> Mac 上有完整源码（`03-代码/template2026_ws/` + `06-备份/2026-11-18-fig8-定版包.tgz`），
> 机器上删干净不影响我们下次飞 —— 明天要用再 `scp` 一次，20 秒的事。

### 顺手清（脚本不碰，可选）

```bash

history -c; rm -f ~/.bash_history       # 命令行历史里有我们的 sed 参数
```
