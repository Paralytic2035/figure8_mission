
## 第 3 步 · 改成「第一飞」参数（6–7 分钟）

```bash
cd ~/template2026_ws/src/mission/config && sed -i 's/^curve_a: [0-9.]*/curve_a: 0.45/; s/^laps: [0-9]*/laps: 1/; s/^track_mode: [a-z]*/track_mode: progress/; s/^k_gate: [0-9.]*/k_gate: 0.30/; s/^dev_max: [0-9.]*/dev_max: 1.0/' figure8.yaml && grep -nE '^(curve_a|laps|track_mode|k_gate|dev_max|ctrl_mode|yaw_mode|if_debug)' figure8.yaml
```

**核对点**，七行都要对：

```
curve_a: 0.45
k_gate: 0.30
track_mode: progress
ctrl_mode: pos
laps: 1
yaw_mode: fixed
dev_max: 1.0
if_debug: 0
```

> `dev_max` 从包里默认的 0.30 放宽到 **1.0**：几乎不会被触发（正常误差只有 0.05–0.1 m），
> 万一真飞偏也不会中途停住，让它直接飞完。想彻底关掉就改成 `9.0`。
