## 二、卡死问题（重要，我方 bug）

### 现象

```
s=1.09/13.68 m  e=-0.034 m  v=0.45  κ=3.91  yaw=0.0°     ← 每 0.5 s 一模一样，卡了 40+ 秒
```

飞机停在轨迹上（e 只有 −0.034 m），但 `s` 纹丝不动。

### 根因：进度门控 + 纯位置 = 死锁

```
门控：s_cmd 最多领先 s_act 0.45 m（k_gate）
飞机追到了那个"胡萝卜" → 位置误差≈0 → 不再移动 → s_act 不涨
s_act 不涨 → s_cmd 被压回 s_act + 0.45 → 胡萝卜也不动
→ 双方互等，永久静止
```

**为什么仿真没抓到**：纯数学闭环用的是"一阶滞后"模型，飞机永远差一点点追不上胡萝卜；
真机 PX4 位置环收敛到厘米级，**真的追到了**，于是进入死锁。这是模型没覆盖到的失效模式。

### 处理

- **当天**：改 `track_mode: timed`（参考点按时间匀速前进，不看追没追上，逻辑上不可能死锁）
  + `v_max 0.32 / v_min 0.25`（让稳态滞后约 0.45 m，切角程度和原来一致）。yaml 改动，不重编译。
- **代码层修复**（已写进 template.h，未实飞验证）：门控加"停滞释放"——
  若 `s_act` 连续 0.5 s 没有增长，就不再压 s_cmd，让参考点逃出去。
