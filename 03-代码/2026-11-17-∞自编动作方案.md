## 二、几何与速度（已数值定标）

采用**伯努利双纽线**（曲率处处连续，无 Gerono 那种尖角）：

```
x(t) = a·cos t / (1 + sin²t)
y(t) = y_scale · a·sin t·cos t / (1 + sin²t)
```

实测数值（Python 复数步长法算得）：a=0.5、y_scale=1.41 → x ∈ ±0.500、y ∈ ±0.249、弧长 **L = 3.04 m**、κ_max = 6.26 1/m（R_min = 0.16 m）。

| 参数 | 值 | 说明 |
|---|---|---|
| a | 0.5 m | 半长轴，严格贴合已确认场地 |
| y_scale | 1.41 | 把 y 拉到 ±0.25，纵横 2:1，视觉像标准 ∞ |
| L | 3.04 m | 一圈弧长 |
| v_max / v_min | 0.45 / 0.30 m/s | 曲率限速 v = min(v_max, √(a_lat_max·R)) |
| a_lat_max | 1.2 m/s² | 对应最大倾角 ~7°，330 机型余量充足 |
| 单圈 T | 6.1–6.8 s | 满足"单圈约 6 s" |
| 3 圈 | 约 20–21 s | 加起降全程 < 40 s |

**为什么选它**：

1. 交叉点正好是起飞点 (0,0) → **起飞即入轨**，不用先飞一个入轨点；
2. 曲率连续，没有括号式尖角（Gerono a=b=0.5 的 R_min 只有 0.104 m，实机必被"切角"）；
3. 3 圈后自然回到原点，落地位置安全。

**曲率对照数据**（备说明引用）：

| 曲线 | 尺寸 | L | κ_max | R_min |
|---|---|---|---|---|
| Gerono a=b=0.5 | 1.0×0.5 | 3.05 m | 9.58 | 0.104 m |
| Gerono a=0.5 b=0.3 | 1.0×0.3 | 2.50 m | 7.95 | 0.126 m |
| Bernoulli a=0.5（等比） | 1.0×0.35 | 2.62 m | 6.00 | 0.167 m |
| **Bernoulli a=0.5 y_scale=1.41** | **1.0×0.5** | **3.04 m** | **6.26** | **0.160 m** |

## 三、改造结构（创意性 3 分的主线：四层，全部可验证）

### L1 库层能力（`template.h` 新增，不改任何现有函数签名）

- `TrajRef` 结构体 + `traj_send(ref, use_vel_ff)`：统一打包 position + 前馈 velocity + yaw + init 偏移，**含两种 type_mask 模式**（`pos_ff` / `vel`），对齐 `circle_advanced` 与 `avoidance` 已验证的两种写法。
- `PathLUT` + `path_build / path_project / path_sample`：任意曲线 → 等弧长采样表（N=2000，含 s、P、切向 T、法向 N、曲率 κ）。**这是这次真正的库升级**：以后第五关的连续航段可直接复用。
- `StatTracker`（RMSE / 最大偏差 / 幅值 / 闭合误差）+ `traj_marker_publish`（理论曲线蓝、实际轨迹绿）+ CSV 落盘。

### L2 跟踪律（"比定点难在哪"就是要讲的东西）

- **自动入轨点**：`find_enter_s()` 在弧长表里找离起飞原点最近、切向最接近 +x 的分支（双纽线自交点在 s=0.25L/0.75L，不是 0.5L —— 这个坑已被自测抓到）。
- **弧长进度 + 时间门控**：参考点按名义速度推进 `s_cmd += v_cmd·dt`；每周期用**单调窗口（±0.4 m）弧长投影**测出实际进度 `s_act`；若 `s_act < s_cmd − 0.15` 则冻结 `s_cmd`，落后者先保形状、不赶时间。
- **前馈速度**：`v_ff = v_cmd·T(s_cmd) + k_ct·e_cross·N`（横向纠偏），解决"位置滞后 → ∞ 缩水"。
- **曲率限速**：按预计算 κ(s) 在两端尖角降速，中间加速。
- **完成判据用实际弧长**（`Δs_act ≥ 3L`），不靠计时，不会因为慢而少飞一圈（对比官方 square 的时间驱动）。

### L3 yaw 策略（现场最容易翻车的点）

square 实测：yaw 是瓶颈（航点 0 等机头转了 13 s）。所以 yaw 做成 yaml 三档：

- `fixed`（yaw=0，保底，首飞用）
- `sweep`（yaw = A·sin(2t)，A=0.25 rad，速率 ≤ 0.8 rad/s，视觉像"跟着 ∞ 摆头"，**默认现场用**）
- `tangent`（切向朝向；尖角处 2.8 rad/s 太快，只作对照实验，不现场用）

### L4 安全与可观测

- 横向偏差 > `dev_max`(0.3 m) 持续 0.5 s → **冻结参考 + 原地悬停 + 告警**，不自动降落（在 1 m 场地里降落比悬停更危险）。
- 总时长 > `laps·T·2` → 直接回原点降落。
- 日志 1 Hz 节流（不再像官方那样刷屏），CSV 写 `~/.ros/fig8-<时间>.csv`，落地后 `scp` 回 Mac 出图。

## 六、数据流与接口

- **输入**：`/mavros/local_position/odom`（复用 `local_pos_cb`）、`mavros/state`。
- **输出**：
  - `/mavros/setpoint_raw/local` 20 Hz（心跳要求 ≥2 Hz，沿用现有 20 Hz）；
  - `/mission/fig8_err`（Float32MultiArray：s_cmd, s_act, e_cross, v_cmd, κ, 圈数占比）；
  - `/mission/fig8_marker`（RViz：理论曲线 + 实际轨迹）。
- **坐标系**：全部相对起飞原点（与 `mission_pos_cruise` 同一套约定，z 加 `init_position_z_take_off`），ENU 数值 + `coordinate_frame=1`，由 mavros 转 NED。
- **参数**只经 yaml → `nh.param`，与现有三个任务节点一致。

## 七、边界情况与失败模式

| 情况 | 处理 |
|---|---|
| 弧长投影在自交点歧义 | 窗口化 + 单调约束（只允许 ±0.4 m 内、不回退），避免跳到另一瓣 |
| 位置滞后导致 ∞ 缩水 | 前馈速度 + 进度门控；两者都失效则切 `ctrl_mode: vel`（纯速度，形状由外环保证） |
| 前馈在 PX4 上不生效（`circle_advanced` 未验证） | 备 M2：`ctrl_mode: vel`（`avoidance` 已验证的 mask），或退回纯位置 + 参考幅值放大 1.1 倍 |
| 偏差超限 | 冻结 + 悬停 + 告警，等人接管（SwD） |
| 起飞高度未达 / 到点判据永不满足 | 沿用 square 的 3 s 超时兜底 |
| 末圈闭合误差大 | 回原点段用保守的 `mission_pos_cruise`，不直接切降落 |
| 仿真 `run_task.sh` 若为白名单 | 先 `cat tools/run_task.sh`；不支持则直接 `roslaunch mission figure8.launch` |
